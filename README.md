### 3. Pilih Konfigurasi
- **Platform:** WhatsApp Bot / Telegram Bot
- **Base:** 
    - `ESM` = Modern - import/export - plugins folder
    - `CASE` = Classic - require - switch case - single file
- **Koneksi:** Pairing Code (8 digit) / QR Code
- **Thumbnail Menu:** Tanpa / Pakai (upload jpg/png)
- **Tampilan Menu:** Premium Box / Simple / Image
- **Gaya Tombol:** Teks Biasa / Button

### 4. Pilih 11 Fitur - Force 11 File
Centang semua biar jadi 11 file - `welcome`, `antilink`, `sticker`, `downloader`, `ai`, `group`, `rpg`, `store`, `autoreply`, `broadcast`, `menu`

### 5. Generate & Download
Klik `Generate Script - 11 File` -> Tunggu -> `Download ZetsuLuyy.zip`
